# پنل مدیریت و آنالیز اینستاگرام — نسخه سرور (v2)

نسخه چندکاربره با **ثبت‌نام/ورود، پنل کاربری و پنل ادمین**.

## ساختار

```
├── index.html        صفحه ورود و ثبت‌نام (عمومی)
├── app.html          پنل کاربری: داشبورد اینستاگرام (نیازمند ورود)
├── admin.html        پنل ادمین: مدیریت کاربران و تنظیمات (نقش ادمین)
├── api/
│   ├── app.py            بک‌اند Flask + SQLite (مسیرهای /api/…)
│   ├── requirements.txt
│   └── seed_admin.py     ساخت ادمین اولیه
└── install.sh        اسکریپت نصب آسان روی VPS اوبونتو (نسخه ۲)
```

## فلوها

**عضویت و ورود**
۱. کاربر در صفحه اصلی ثبت‌نام می‌کند → حساب با وضعیت «در انتظار تأیید» ساخته می‌شود.
۲. ورود قبل از تأیید ممکن نیست و پیام «در انتظار تأیید مدیر» نمایش داده می‌شود.
۳. ادمین در پنل ادمین ← «درخواست‌های تأیید» ← تأیید/رد.
۴. پس از تأیید، کاربر وارد **پنل کاربری** (`/app.html`) می‌شود.

**نقش‌ها**
- `user`: پنل کاربری (داشبورد، ویرایش پروفایل/گذرواژه)
- `admin`: علاوه بر پنل کاربری، دسترسی به **پنل ادمین** (`/admin.html`)

**پنل ادمین**
- نمای کلی: شمار کاربران، در انتظار، فعال، ادمین‌ها + تازه‌ترین عضویت‌ها
- درخواست‌های تأیید: تأیید/رد با یک کلیک
- کاربران: جست‌وجو، فعال/غیرفعال، تغییر نقش، حذف (با محافظت از آخرین ادمین و حساب خود)
- تنظیمات سایت: نام سایت و اطلاعیه (در صفحه ورود نمایش داده می‌شود)

## نصب روی سرور

```bash
git clone https://github.com/younih/instagram-panel.git
cd instagram-panel
sudo bash install.sh panel.example.com
```

اسکریپت نصب می‌کند: `nginx` + `python3-venv` + `certbot`، فرانت در
`/var/www/instagram-panel`، بک‌اند در `/opt/panel` (venv + SQLite در
`/opt/panel/data`)، سرویس دائمی `panel-api` (gunicorn روی `127.0.0.1:8000`)،
پروکسی `/api/` در nginx و گواهی HTTPS.

- در **نصب اول** از شما ایمیل و گذرواژه **ادمین اولیه** پرسیده می‌شود.
- در **به‌روزرسانی** (`git pull` + اجرای دوباره اسکریپت) دیتابیس، کاربران و
  تنظیمات حفظ می‌شوند.

## API (خلاصه)

| مسیر | دسترسی | توضیح |
|---|---|---|
| `POST /api/auth/signup` | عمومی | ثبت‌نام (وضعیت pending) |
| `POST /api/auth/login` | عمومی | ورود (نشست کوکی امن) |
| `POST /api/auth/logout` | عمومی | خروج |
| `GET /api/auth/me` | لاگین | کاربر جاری |
| `GET/PUT /api/user/profile` | کاربر | پروفایل و تغییر گذرواژه |
| `GET /api/admin/stats` | ادمین | آمار کلی |
| `GET /api/admin/users` | ادمین | فهرست کاربران (`?status=pending`) |
| `POST /api/admin/users/<id>/approve\|reject\|disable\|enable` | ادمین | تغییر وضعیت |
| `PUT /api/admin/users/<id>` | ادمین | تغییر نقش |
| `DELETE /api/admin/users/<id>` | ادمین | حذف کاربر |
| `GET/PUT /api/admin/settings` | ادمین | تنظیمات سایت |
| `GET /api/public/site` | عمومی | نام سایت و اطلاعیه |
| `GET /api/health` | عمومی | سلامت سرویس |

## نکات امنیتی

- گذرواژه‌ها با هش امن ذخیره می‌شوند؛ نشست‌ها کوکی `HttpOnly` + `SameSite=Lax` دارند.
- کلید امضای نشست در `/opt/panel/data/secret.key` به‌صورت خودکار ساخته و نگهداری می‌شود.
- دیتابیس SQLite برای شروع کافی است؛ برای مقیاس بزرگ‌تر می‌توان به PostgreSQL مهاجرت کرد.

## توسعه محلی

```bash
cd api && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
PANEL_DATA_DIR=./data .venv/bin/python app.py   # http://127.0.0.1:8000
```
