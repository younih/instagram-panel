# پنل مدیریت اینستاگرام — نسخه استقرار روی VPS

این ریپو نسخهٔ نمایشی (استاتیک، با دادهٔ نمونه) پنل مدیریت اینستاگرام است،
آمادهٔ انتشار روی سرور شخصی.

## پیش‌نیازها

- یک VPS با اوبونتو ۲۲.۰۴ یا ۲۴.۰۴ و دسترسی root/sudo
- یک ساب‌دامنه (مثلاً `panel.example.com`)

## مرحله ۱ — رکورد DNS در کلادفلر

در پنل Cloudflare دامنه‌تان:

1. وارد بخش **DNS** شوید و یک رکورد اضافه کنید:
   - Type: `A`
   - Name: نام ساب‌دامنه (مثلاً `panel`)
   - IPv4 address: آی‌پی سرور VPS
   - Proxy status: **Proxied** (ابر نارنجی روشن)
2. در بخش **SSL/TLS** حالت رمزنگاری را روی **Full (strict)** بگذارید.

## مرحله ۲ — اجرای اسکریپت نصب روی سرور

```bash
git clone <آدرس-این-ریپو>
cd instagram-panel
sudo bash install.sh panel.example.com
```

اسکریپت به‌صورت خودکار انجام می‌دهد:

1. نصب `nginx` و `certbot`
2. انتشار فایل‌های سایت در `/var/www/instagram-panel`
3. ساخت کانفیگ nginx با هدرهای امنیتی پایه
4. فعال‌سازی فایروال (`ufw`) — فقط پورت‌های ۲۲، ۸۰ و ۴۴۳ باز می‌ماند
5. دریافت گواهی رایگان HTTPS از Let's Encrypt و ریدایرکت http به https

## مرحله ۳ — بررسی

مرورگر را باز کنید: `https://panel.example.com`

## به‌روزرسانی بعدی پنل

هر وقت نسخهٔ جدیدی از پنل منتشر شد، کافی است روی سرور اجرا کنید:

```bash
cd instagram-panel
git pull
sudo cp index.html /var/www/instagram-panel/index.html
```
